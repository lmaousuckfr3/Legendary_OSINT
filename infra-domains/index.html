    🌍 Domains, IPs & Infrastructure

    ← Back to Index

    Registries and Whois

    • Whois — Basic Whois lookup
    • ICANN Whois — Official ICANN Whois
    • ARIN — North America IP registry
    • RIPE — Europe, Russia, Middle East IP registry
    • APNIC — Asia-Pacific IP registry
    • LACNIC — Latin America and Caribbean IP registry
    • AFRINIC — Africa IP registry
    • Apnic WhoWas — Historical Asia-Pacific domains
    • SIDN — Netherlands domain registry
    • Eurid — .EU domain registry

    Domain Intelligence

    • DomainTools — Domain research platform
    • DomainIQ — Domain intelligence and history
    • Completedns — DNS history database
    • WhoisRequest — Domain ownership history lookup
    • DomainBigData — Domain ownership and historical data
    • SecurityTrails — DNS and infrastructure data
    • Robtex — Infrastructure graph explorer

    Certificates and DNS

    • CertDB — Historical SSL certificates
    • crt.sh — Certificate Transparency logs
    • PassiveDNS (Mnemonic) — Historical DNS resolution
    • DNSDumpster — DNS mapping and reconnaissance
    • DNSlytics — DNS, IP, and ASN intelligence
    • ViewDNS — Multi-tool for DNS and Whois lookups

    Technology Fingerprinting

    • BuiltWith — Website technology profiler
    • Wappalyzer — Detect CMS, frameworks, and technologies
    • Netcraft — Site reports and hosting analysis
    • SpyOnWeb — Shared analytics and advertising IDs
    • VisualSiteMapper — Website relation mapping

    IP Tools

    • IPVoid — IP lookup and blacklist checks
    • GeoIP Tool — Approximate IP geolocation
    • CentralOps — Network lookup toolkit
    • Network-Tools — Classic network OSINT (legacy)
    • I Know What You Download — Torrent history by IP

    Domain Age and History

    • CarbonDate — Estimate when a domain was created
    • Webotheek.nl — Dutch .nl domain research
    • Timer4Web — Detect changes and analytics IDs (partial free, paid features)
    • Whois EasyCounter — Historical Whois and ownership details
    • WhyNoHTTPS — Database of sites without HTTPS

    Website Relationship & Similarity

    • SimilarSites — Find websites similar to a given domain
    • SitesLike — Discover alternative sites and competitors
