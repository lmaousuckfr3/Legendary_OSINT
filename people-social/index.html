    Cross-Platform

    • Sherlock — Username search across 350+ sites
    • WhatsMyName — Fast username enumeration
    • Maigret — Collect profiles by username across 2000+ sites
    • Holehe — Check if email is registered on platforms
    • Blackbird — Alternative username search engine
    • Namechk — Username/domain availability
    • Socialscan — Check username/email across services
    • UserSearch — Find usernames across forums, social, communities
    • IDcrawl — Meta search for people across multiple social networks
    • PeekYou — Publicly available people search
    • Pipl — Commercial people search & enrichment

    Twitter / X

    • Twint — Scrape Twitter without API keys
    • snscrape — Scrape tweets, profiles, hashtags
    • TweetBeaver — Lookup tools for profiles, likes, followers
    • Foller.me — Analyze Twitter account topics & activity
    • BirdHunt — Historical tweet search
    • Twitonomy — Analytics on tweets, mentions, followers, lists
    • Bot Sentinel — Detect and analyze bot-like or inauthentic accounts
    • Wayback Tweets — Retrieve deleted or archived tweets
    • Nitter — Alternative Twitter front-end, useful for OSINT scraping

    Instagram

    • Instaloader — Download posts, stories, metadata
    • OSINTgram — Command-line Instagram OSINT
    • InstaLooter — Download profile content
    • Picuki — Instagram web viewer/downloader
    • StoriesDown — Download Instagram stories anonymously
    • InstaDP — View and download profile pictures

    LinkedIn

    • RocketReach — Email/profile enrichment (freemium)
    • SignalHire — LinkedIn email extraction (freemium)
    • Hunter.io — Corporate email discovery
    • PhantomBuster — Automate LinkedIn scraping (freemium)
    • SalesQL — LinkedIn lead & contact extraction

    TikTok

    • TikTok-OSINT — Extract TikTok profile data
    • TikTok-Scraper — Download videos, scrape metadata
    • Urlebird — View TikTok profiles without login
    • Exolyt — TikTok analytics & monitoring (freemium)

    Reddit

    • Pushshift Reddit Search — Historical Reddit data
    • Reddit Insight — Analyze profiles & posting activity
    • ReSavr — Recover deleted comments
    • Camas Reddit Investigator — Search Reddit posts & comments
    • Redective - The Reddit Search Detective

    Snapchat

    • SnapChat Political Ads Database - Political Ads Database starting from 2018
    • SnapChat Explore - Use search bar to search for usernames, tags f.e.
    • Snaplytics - Several tools to download profile pictures, stories and videos

    YouTube

    • YTCommentSearch — Search video comments
    • Noxinfluencer — YouTube channel analytics
    • Channel Crawler — Find channels by keyword/topic
    • Social Blade — Stats on YouTube/Twitch/Twitter accounts
    • YouTube Metadata - Grabs details about a video/uploader/playlist/creator/channel
    • YoutTube Geolocation - Find videos based on geolocation
    • YouTube Video Finder - Find (archived) YouTube videos

    Telegram

    • Telegago — Group/channel OSINT
    • TgScan — Search public groups/channels
    • TGDB - Searchable Telegram database service
    • Telemetr.io - Telegram analytics suite
    • IntelX - Telegram - IntelX Telegram Search
    • Telepathy — Extract account info via API
    • FindThatGroup — Public group/channel directory
    • Combot — Top Telegram groups/channels
    • TLGrip — Telegram scraper for groups/chats
    • Telegram Channels - Search Telegram Channels
    • Telemetry - Telegram analytics tool
    • Tgstat - Russian-based Telegram analytics tool

    Discord

    • Disboard — Server directory
    • Discord Lookup — Lookup user IDs
    • Snowsta — Discord snowflake ID OSINT
    • Guild.xyz — Explore Discord guilds & communities

    Facebook

    • StalkFace — Extract hidden profile info
    • Lookup-ID — Get Facebook IDs from URLs
    • GraphTips — Facebook graph search revival
    • Social Search Facebook — Search within Facebook

    GitHub

    • React GitHub Notetaker — GitHub Username Search
    • GitHub Username Search Engine — Does what the name says
    • GitHub Tending RSS — RSS feed trending topics
    • GitHub Dorking List — List of useful GitHub dorks

    VKontakte (VK) OSINT

    • VK Watch — Search for profiles, posts, videos, and groups
    • Bellingcat VK Scraper — Python tool to scrape profiles, photos, and groups
    • VK ID Lookup — Find a VK profile by numeric ID or slug
    • vk_api (Python) — Unofficial Python library for VK API access
    • vk-grabber — Bulk scraping of VK photos and posts
    • Wayback Machine — View archived/removed VK content
    • OSINTCombine VK Guide — Practical guide for VK investigations
    • Search4Faces — Reverse face search across VKontakte
    • VK History Robot — Telegram bot to view VK profile history changes
    • FindNameVk Bot — Telegram bot to search for VK profiles by name
    • Дезертир — Telegram tool for VK-related OSINT (Russian)
    • Barkov.net — VK user and community search engine
    • VK5 — VK search engine and analytics tool
    • VK Community Search — Discover VK groups and communities
    • VK People Search — Find VK users by various filters
